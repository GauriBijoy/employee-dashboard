# Employee Dashboard (React)

A React assignment project with:
- Home dashboard showing `id`, `name`, and `email` from JSONPlaceholder.
- Employee Form with Name, Designation, Location, and Salary fields.
- React Router navigation between Home and Employee Form.
- Bootstrap and custom CSS for responsive styling.
- No backend and no form data submission.

## Requirements
Install Node.js (LTS) from https://nodejs.org/ and use VS Code.

## Run locally
1. Extract the ZIP file.
2. Open the `employee-dashboard` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## GitHub submission
1. Create a new empty repository on GitHub named `employee-dashboard`.
2. In VS Code terminal, from the project folder, run:
   ```bash
   git init
   git add .
   git commit -m "Create React Employee Dashboard"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/employee-dashboard.git
   git push -u origin main
   ```
3. Replace `YOUR-USERNAME` with your GitHub username.
4. Submit the repository URL, for example:
   `https://github.com/YOUR-USERNAME/employee-dashboard`

Do not upload the `node_modules` folder. It is created by `npm install` and is excluded by `.gitignore`.
